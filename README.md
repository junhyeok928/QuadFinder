# QuadFinder

Everything의 빠른 파일명 검색과 Q-Dir의 다중 패널 탐색 경험을 결합하는 Windows 파일 관리자입니다.

![확정한 디자인 시안](docs/design-concept.png)

## 현재 구현 — v0.10.0

네비게이션의 주요 글자는 파일 이름과 같은 **14px**입니다. 이전 **90% 크기를 새 100% 기본값**으로 사용합니다. Ctrl+휠과 Ctrl+0은 새 기준으로 동작하고 배율은 저장합니다. 이전 기본 100% 및 90% 설정은 새 기본값으로 옮기며, 그 외 사용자 배율은 가능한 한 기존 크기를 유지하도록 변환합니다.

### 출시 전 설치 마법사

`pnpm package` 후 `pnpm wizard`로 `release/0.10.0/wizard/QuadFinder-0.10.0-Preview-Setup.exe`를 만듭니다. 공개 릴리스는 생성하지 않습니다. 한글 환영 화면 → 구성 요소/바로가기 → 설치 위치 → 설치 진행 → 완료/선택 실행을 제공합니다. 기본 위치는 `%LOCALAPPDATA%\Programs\QuadFinderPreview`이고 기존 Squirrel 설치와 별도입니다. 미리보기 설치본은 자동 업데이트를 확인하지 않습니다.

![설치 마법사 환영 화면](docs/wizard-welcome.png)

Windows 설치된 앱 또는 시작 메뉴의 **QuadFinder 제거**로 제거할 수 있습니다. 제거 마법사는 설정을 기본 보존하며, 선택하면 설정·즐겨찾기·검색 인덱스 파일도 지웁니다. 설정 위치 `%APPDATA%\QuadFinder`는 다른 설치본과 공유할 수 있으므로 선택 삭제 시 함께 초기화됩니다. 문서와 즐겨찾기에 연결된 실제 폴더는 삭제하지 않습니다. 앱이 실행 중이면 먼저 종료하도록 안내합니다.

NSIS 3.12 도구 묶음을 빌드 시 다운로드하고 고정 SHA-256으로 검증합니다. 개발 PC에 설치 도구를 별도 설치하거나 레지스트리에 등록하지 않습니다. `pnpm wizard:check`는 격리된 폴더·전용 테스트 레지스트리·테스트 바로가기로 설치/재설치/제거/설정 보존/선택 삭제를 확인하고, 실제 미리보기 설치 파일의 해시·현재 소스·앱/네이티브 도우미 포함을 검증합니다. `node scripts/check-wizard.cjs --screenshots`는 직접 만든 테스트 마법사의 환영·구성 요소·위치 화면도 캡처합니다. 검사에서 기존 설치나 실제 사용자 설정을 변경하지 않습니다.


색상 테마는 **뉴트럴 블랙**과 **실버 라이트**입니다. 우측 상단의 `테마`에서 전환하며 선택은 재실행 후에도 유지됩니다. 메뉴·대화상자·미리보기·작업 창에도 동일한 색상을 적용합니다. 기본은 뉴트럴 블랙입니다.

[뉴트럴 블랙 화면](docs/implementation-preview.png) · [실버 라이트 화면](docs/silver-light-preview.png)

왼쪽 `최근 폴더`에 최근 방문한 폴더를 최대 10개까지 최신순으로 저장합니다. 재방문한 폴더는 맨 위로 이동하며, 검색·자동 새로고침·앱 시작 시 탭 복원은 방문 기록을 바꾸지 않습니다. 클릭하면 활성 패널에서 열고 Ctrl+클릭 또는 휠클릭하면 새 탭에서 엽니다. 접기 상태와 기록은 자동 저장됩니다. 우클릭에서 개별 기록을 제거하거나 `기록 지우기`로 전체를 지울 수 있으며 실제 폴더는 삭제하지 않습니다. 상단 검색 필터는 전체·문서·이미지만 표시합니다.

패널 사이의 경계를 드래그해 좌우·위아래 비율을 조절합니다. 비율은 자동 저장되며 더블클릭으로 균등 분할, 포커스한 경계에서 방향키·Home·End로 조절할 수 있습니다. 드래그 중 Escape는 이전 비율로 돌아갑니다. 작은 화면에서는 최소 크기를 지키며 위아래 조절 공간이 부족하면 세로 스크롤로 탐색합니다. 크기만 바꾸므로 폴더·탭·선택 상태는 유지됩니다.

우측 상단 `실행 취소` 또는 **Ctrl+Z**로 이번 실행에서 완료한 복사·이동·이름 변경을 최대 20개 작업까지 되돌립니다. 여러 파일을 함께 작업했으면 한 번에 되돌립니다. 파일 내용과 경로를 확인하고, 이후 수정된 파일이나 원래 위치의 충돌이 있으면 중단합니다. 복사본 제거는 휴지통을 사용합니다. 삭제 복원과 재실행 이후의 실행 취소 기록 복원은 지원하지 않습니다. 직접 삭제 작업을 하면 이전 기록을 비워 다른 작업을 실수로 되돌리지 않도록 합니다. 내용 검증은 파일을 다시 읽으므로 큰 파일에서는 시간이 걸릴 수 있습니다.

Everything 연동은 추가하지 않으며 별도 검색 프로그램 설치 없이 자체 로컬 인덱스를 사용합니다. 네트워크 인덱싱 제외 정책도 유지합니다.

폴더·문서·돋보기 모양의 대표 아이콘을 창·작업 표시줄·실행 파일에 적용했습니다. 원본은 `assets/app-icon.svg`이며 `pnpm icon:build`로 PNG와 Windows ICO(16~256px)를 다시 생성할 수 있습니다.

시안의 한 줄 검색 도구 모음, 컬러 파일 아이콘, 폴더 경로 표시, 패널 비율과 글자 크기를 반영했습니다. 드라이브 사용량은 실제 로컬 볼륨에서 읽고, 이미지 파일은 Windows에서 제공하는 썸네일을 표시합니다.

버튼·탭·상태 표시줄은 그라데이션과 그림자 없이 단색으로 표시합니다. 왼쪽 탐색 영역은 파일 이름과 같은 14px 글자와 18px 아이콘으로 구성하며, 오른쪽 경계를 드래그해서 너비를 조절할 수 있습니다. 조절한 너비는 자동 저장됩니다. 경계를 더블클릭하면 기본 너비로 돌아오며, 경계에 포커스한 상태에서 방향키·Home·End로도 조절할 수 있습니다.

Ctrl+마우스 휠로 글자·아이콘·버튼·패널·상태 표시줄을 함께 확대·축소합니다. 배율은 70~150%에서 10%씩 바뀌고 자동 저장됩니다. 일반 휠은 기존처럼 스크롤하며, Ctrl+0 또는 상태 표시줄의 배율 버튼으로 100%로 돌아갑니다. Ctrl++/Ctrl+-도 사용할 수 있습니다.

## 보기 옵션과 우클릭

패널 탭 옆의 보기 옵션 버튼에서 숨긴 항목·확장명·확인란, 정렬·그룹화, 미리보기·세부 정보 창을 설정합니다. 자세히 보기에서는 열 경계를 드래그하거나 더블클릭해서 너비를 맞추고, 열 제목을 드래그하여 순서를 바꿉니다. 열 제목 우클릭으로 열을 추가·제거할 수도 있습니다. 설정은 폴더별로 저장하며 보기 옵션에서 초기화할 수 있습니다.

![보기 옵션 — 예시 데이터](docs/view-options.png)

![우클릭 메뉴 — 예시 데이터](docs/context-menu.png)

기본 우클릭 메뉴는 Windows 11의 아이콘 명령 모음과 구분선·배치를 앱의 평면 다크 UI에 맞춰 구현했습니다. **더 많은 옵션 표시** 또는 **Shift+우클릭**은 Windows IContextMenu가 제공하는 실제 확장 메뉴를 엽니다. 이는 Windows 11의 새 메뉴 자체가 아니라 탐색기의 확장 메뉴에 해당하며, 시스템 테마와 설치된 셸 확장에 따라 모양과 항목이 달라집니다. 검색 결과에서 서로 다른 폴더의 파일을 함께 선택한 경우 시스템 확장 메뉴는 같은 폴더별로 사용해야 합니다. 셸 확장 명령의 진행·확인 창은 해당 프로그램이 제공하며 앱의 작업 큐와 별도로 동작합니다.

미리보기는 로컬 텍스트(앞부분 128 KB), PNG/JPEG/WebP/BMP/GIF/AVIF 이미지와 PDF를 지원합니다. 40 MB를 초과하는 파일은 내용 미리보기를 생략합니다. 텍스트와 HTML은 실행하지 않고 글자로 표시하며 PDF는 Chromium의 PDF 뷰어를 사용합니다. Word·Excel 본문 미리보기는 아직 지원하지 않습니다.

## 네비게이션

- 즐겨찾기·내 PC 제목을 클릭하거나 Enter/Space로 접기·펼치기. 접힘 상태는 저장됩니다.
- 각 항목 왼쪽 화살표로 하위 폴더를 펼칩니다. 실제로 펼친 폴더만 읽고, 접힌 섹션의 하위 폴더는 펼칠 때 불러옵니다. 오류 시 다시 시도할 수 있습니다.
- 현재 폴더 고정 버튼, 폴더 경로 입력 또는 선택으로 로컬·UNC 폴더를 추가합니다. `검색 대상에도 포함`을 끄면 바로가기만 추가합니다.
- 추가한 바로가기의 드래그 순서 변경, 우클릭으로 표시 이름 변경·위아래 이동·제거. 표시 이름과 순서를 저장하며 실제 폴더는 변경하지 않습니다.
- Ctrl+클릭·휠클릭 또는 우클릭 메뉴로 새 탭에서 열기, 다른 패널에서 열기, Windows 탐색기 열기, 경로 복사·속성을 제공합니다.
- 즐겨찾기 제목이나 고정 영역에 폴더를 놓으면 바로가기로 고정합니다. 폴더 항목에 파일을 놓으면 해당 폴더로 복사하고 Shift를 누르면 이동합니다.
- 바로가기 제거와 검색 대상 제외는 별도 명령입니다. 네비바에서 Delete는 추가한 바로가기만 제거하며 실제 폴더를 삭제하지 않습니다.
- 네비바 새로고침 버튼·F5로 폴더 트리와 드라이브 용량을 다시 확인합니다. 방향키로 항목 이동·펼치기·접기를 지원하며 목록이 길면 네비바 안에서 스크롤합니다.

## 자동 갱신과 네트워크 폴더

파일 변경 알림은 해당 폴더를 표시하는 패널에만 반영합니다. 앱이 포커스를 잃으면 화면 갱신을 보류하고, 포커스가 돌아오면 한 번에 갱신합니다. 목록이 같으면 다시 그리지 않고, 실제 변경이 있더라도 탭·주소 표시줄·스크롤·선택 상태를 유지합니다. 검색 인덱스의 진행 알림마다 검색 화면을 비우던 동작도 제거했습니다.

사이드바는 현재 활성 패널의 경로에 맞춰 가장 가까운 즐겨찾기·추가 폴더를 강조합니다. 패널·탭 전환과 뒤로가기 후에도 선택 표시를 동기화합니다.

`폴더 추가`에서 `\\NAS\공유폴더`를 즐겨찾기로 추가할 수 있습니다. **모든 UNC 공유 경로와 Windows 네트워크 드라이브는 검색 인덱싱에서 제외**합니다. 기존 네트워크 검색 대상은 시작 시 즐겨찾기로 전환하고, 캐시에 남은 해당 파일도 검색에서 제외합니다. 폴더 탐색·파일 작업·보기 설정은 계속 사용할 수 있습니다. UNC 주소 표시줄은 서버와 공유 이름을 하나의 루트로 취급합니다. 네트워크 변경 감지는 서버마다 달라 포커스 복귀 또는 F5로 보이는 폴더를 다시 확인합니다.

인덱싱은 변경된 파일의 메타데이터 또는 폴더의 직계 목록을 확인하고, 새 하위 폴더만 재귀 수집합니다. 전체 재수집 중에도 확인한 항목을 검색할 수 있습니다. Windows FindFirstFileEx/FindNextFile로 폴더 항목과 메타데이터를 함께 읽어 개별 파일 stat 호출을 줄입니다. 긴 경로도 지원합니다. 폴더 응답은 최대 15초까지 기다리며, 접근 실패 시 기존 데이터를 보존합니다. 상태 표시줄의 인덱싱 문구를 클릭하면 권한 부족·시간 초과·경로 사라짐·기타 오류와 문제 경로(최대 200개)를 확인할 수 있습니다. 상태 표시줄에 확인한 폴더 수를 표시하고, 마우스를 올리면 현재 경로와 오류를 확인할 수 있습니다. 검색 대상 변경은 진행 중인 수집을 취소합니다. 변경 없는 재수집에서는 캐시 파일을 다시 쓰지 않습니다.

## 파일 작업

파일을 Ctrl/Shift로 여러 개 선택한 뒤 Ctrl+C 또는 Ctrl+X, 대상 패널에서 Ctrl+V를 사용합니다. 드래그는 기본 복사이고 Shift를 누르면 이동합니다. F6으로 대상 폴더를 직접 골라 이동할 수도 있습니다. Delete는 확인 후 Windows 휴지통으로 보냅니다. 앱 자체 삭제는 휴지통 이동이며, 시스템 확장 메뉴에서 실행하는 명령은 Windows와 설치된 셸 확장 프로그램이 처리합니다.

앱 작업 큐의 이동은 복사를 완료하고 원본이 바뀌지 않았는지 확인한 뒤 원본을 휴지통으로 보냅니다. 따라서 원본은 Windows 휴지통에서 복원할 수 있고, 복사 중에는 추가 여유 공간이 필요합니다. 원본 변경 또는 휴지통 오류가 나면 원본을 유지하고 작업 창에 오류를 표시합니다. 완료된 항목은 작업 취소 시 되돌리지 않습니다. 실행 중인 작업이 있으면 창을 닫기 전에 완료하거나 취소해야 합니다.

앱 작업 큐는 기존 파일을 덮어쓰지 않습니다. 충돌 시 새 이름으로 둘 다 유지하거나 건너뛸 수 있습니다. 연결·정션이 포함된 폴더 복사/이동은 지원하지 않습니다. 네트워크 공유의 휴지통 이동 가능 여부는 Windows와 공유 서버의 지원에 따르며, 실패하면 오류를 표시하고 영구 삭제로 대신하지 않습니다. Windows 파일 클립보드를 공유하므로 탐색기와 Ctrl+C/X/V로 파일을 주고받을 수 있습니다. 외부 파일은 드래그해서 가져올 수 있습니다.

## 개발 실행

Windows x64, Node.js 22 이상과 pnpm 11이 필요합니다. 셸 브리지는 Windows의 .NET Framework 4.x C# 컴파일러로 개발 실행 시 자동 빌드합니다. 패키지에는 컴파일된 브리지가 포함됩니다.

```powershell
pnpm install --frozen-lockfile
pnpm start
```

Electron 설치 시 바이너리가 설치되지 않았다면 `node node_modules/electron/install.js`를 실행합니다. pnpm의 빌드 정책은 `pnpm-workspace.yaml`에서 Electron 설치와 electron-winstaller의 동봉 압축 도구 준비 스크립트만 허용합니다.

```powershell
pnpm test       # 실제 파일 시스템 및 검색 워커 테스트
pnpm smoke      # 실제 UI 선택→복사→충돌→이름 변경→드래그 이동→Windows 휴지통 검증
pnpm preview    # http://127.0.0.1:4173 디자인 확인용, 예시 데이터
pnpm design:check # 시안 크기와 작은 창의 실제 Electron 화면 캡처, 예시 데이터
pnpm package    # release/0.10.0/QuadFinder-win32-x64/QuadFinder.exe
pnpm installer  # release/0.10.0/installer/QuadFinder-0.10.0-win32-x64-Setup.exe
```

## 보호 폴더 인덱싱

상태 표시줄의 **인덱싱 상태 → 관리자 권한으로 다시 인덱싱**을 누르면 Windows UAC 승인 후 읽기 전용 `QuadFinder.Index.exe` 도우미만 승격합니다. 파일 관리자 자체는 기존 권한을 유지합니다. 도우미는 로컬 고정·이동식 드라이브의 이름·크기·시각·속성 열거만 지원하며 파일 본문 읽기·쓰기·ACL/소유권 변경은 지원하지 않습니다. UAC를 취소하거나 연결에 실패하면 일반 권한으로 계속합니다. 관리자 모드는 현재 실행 동안만 유지합니다. Windows가 SYSTEM/TrustedInstaller 등에 제한한 폴더까지 모두 읽을 수 있다고 보장하지 않습니다. 네트워크 제외 정책은 관리자 모드에서도 유지합니다.

일반 권한의 자동 테스트는 SQLite 재시작·25만 건 초과·네이티브 긴 경로·페이지 전송·오류 진단 UI를 검증합니다. 실제 UAC 승인 및 보호 폴더 권한 확대는 사용 환경에서 별도 확인이 필요합니다. 현재 구현은 MFT/USN 인덱서가 아니므로 첫 전체 순회와 재시작 후 변경 확인은 필요합니다.

## 검색 범위와 제한

시작할 때 연결된 로컬 고정·이동식 드라이브를 자동 검색 범위로 사용합니다. 기존 검색 폴더 설정이 있어도 전체 드라이브가 포함되며 폴더를 수동으로 추가할 필요가 없습니다. 네트워크·광학 드라이브는 자동 수집하지 않습니다. 새 드라이브 연결 후에는 앱을 다시 시작하세요. 접근 권한이 없는 폴더는 건너뜁니다. 설정과 인덱스 DB(`index.sqlite`)는 로컬 앱 데이터 폴더에 저장합니다. 기존 JSON 캐시는 한 번 가져오고 보존하지만 더 이상 전체 JSON으로 다시 저장하지 않습니다. 심볼릭 링크·재분석 지점과 앱 자체 설정 폴더, 시스템 휴지통 및 System Volume Information은 제외합니다. `.git`과 `node_modules`는 포함합니다. SQLite 디스크 저장소를 사용하며 이전 25만 항목 제한을 제거했습니다. 검색 결과는 상위 1,000개를 표시합니다. 일반 폴더 목록은 2,000개씩 추가 표시할 수 있습니다. 파일 본문은 검색하지 않습니다.

폴더 변경을 감지해 해당 파일 또는 하위 폴더만 갱신합니다. 주기적인 전체 재수집은 하지 않으며, 변경 감지가 지원되지 않는 볼륨에서는 수동 갱신이 필요합니다. 수동 갱신은 상태 표시줄의 새로고침으로 가능합니다. 첫 수집에는 파일 수와 디스크 속도에 따라 시간이 필요하고, 캐시를 읽은 뒤에는 이전 결과로 검색하면서 갱신합니다.

| 검색어 예시 | 동작 |
|---|---|
| `프로젝트 보고서` | 두 단어를 모두 포함 |
| `"최종 보고서"` | 연속된 구문 포함 |
| `*.pdf` | 파일명 와일드카드 (`*`, `?`) |
| `ext:pdf;docx` | 확장자 조건 |
| `path:Projects` | 경로 조건 |
| `size:>10mb` | 파일 크기 조건 (`b`, `kb`, `mb`, `gb`, `tb`) |

탭 경로는 앱 데이터 폴더에 저장되며 Git에 포함되지 않습니다. 앱은 사용자 파일 목록을 서버로 전송하지 않습니다. Electron 렌더러의 Node 접근을 차단하고, 제한된 preload API로 파일 작업을 수행합니다.

## 구조

`src/main.cjs`는 앱 창·IPC·로컬 설정·폴더 감시를, `src/files.cjs`는 경로 검증과 검색 조건을, `src/operations.cjs`는 파일 작업 큐·검증·취소를, `src/index-worker.cjs`는 별도 스레드의 검색 인덱스와 캐시를 담당합니다. `src/renderer/features.js`에는 파일 선택과 메뉴·작업 UI가 있습니다. 브라우저 미리보기의 예시 데이터는 실제 데스크톱 파일 API와 분리되어 있습니다.

## 설치와 업데이트

설치 파일은 Electron의 Squirrel.Windows 방식으로 만듭니다. `Setup.exe`를 실행하면 사용자 계정에 설치하고 바탕 화면·시작 메뉴 바로가기를 만듭니다. 포터블 폴더도 계속 제공합니다. 설치·제거 시 사용자 파일과 앱 설정을 지우지 않습니다. 현재 코드 서명 인증서는 적용하지 않았습니다.

설치 버전은 시작 후 및 6시간 간격으로 업데이트를 확인합니다. 새 버전을 받으면 우측 상단 `재시작하여 업데이트`를 눌러 적용하며, 파일 작업이나 실행 취소가 진행 중이면 적용하지 않습니다. 포터블 버전의 `업데이트` 버튼은 GitHub 릴리스 페이지를 엽니다.

업데이트 배포에는 **공개된 GitHub Release**가 필요합니다. `Prepare Windows release` 작업을 수동 실행하면 버전을 검증하고 테스트·패키징 후 설치 파일, `.nupkg`, `RELEASES`, `SHA256SUMS.txt`를 초안 릴리스에 올립니다. 확인 후 릴리스를 게시하면 Electron 공식 업데이트 서비스가 해당 공개 배포를 제공합니다. 초안은 자동 업데이트에 제공되지 않습니다. 첫 공개 릴리스가 없으면 자동 업데이트 서버가 새 버전을 제공하지 못합니다. 업데이트 상태 전환·작업 중 설치 차단은 자동 테스트로 검증하며, 공개된 두 버전 간 실제 교체 검증은 별도 단계입니다.

공개 저장소이며 배포 라이선스는 아직 지정하지 않았습니다.
