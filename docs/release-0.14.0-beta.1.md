# QuadFinder v0.14.0-beta.1

Windows 파일 검색과 다중 패널 탐색을 결합한 QuadFinder의 첫 공개 베타입니다.

## 다운로드

| 파일 | 사용 방법 |
| --- | --- |
| QuadFinder-Setup.exe | 현재 사용자 계정에 설치합니다. 기본 위치는 %LOCALAPPDATA%\Programs\QuadFinder입니다. |
| QuadFinder-0.14.0-beta.1-portable-x64.zip | 전체 압축을 풀고 QuadFinder-win32-x64 폴더의 QuadFinder.exe를 실행합니다. |

Windows 10/11 x64를 지원합니다. 설치 화면에는 .NET Framework 4.8이 필요합니다. 두 버전 모두 설정과 검색 인덱스를 %APPDATA%\QuadFinder에 저장합니다. 포터블은 설치 없이 실행하는 방식이며 설정을 USB에 별도 보관하는 방식은 아닙니다.

## 주요 기능

- 자체 SQLite 인덱스로 PC 로컬 파일 이름 검색
- 1·2·4분할 탐색, 독립 탭, 패널 크기 조절
- 8가지 파일 보기, 정렬·그룹화, 텍스트·이미지·PDF 미리보기
- 영역 드래그 선택, 복사·이동·이름 변경·휴지통 삭제
- 충돌 시 둘 다 유지·건너뛰기·덮어쓰기, 작업 진행·취소와 실행 취소
- Windows 우클릭 메뉴·클립보드 연동, 즐겨찾기와 최근 폴더
- 뉴트럴 블랙·실버 라이트 테마, Ctrl+휠 전체 배율 조절
- 첫 실행 인덱싱 안내와 간단한 사용 설명

## 사용 전 안내

- 첫 인덱싱은 파일 수와 디스크 속도에 따라 시간이 걸릴 수 있습니다. 수집 중에는 검색 결과가 일부만 표시되며 폴더 탐색은 계속 사용할 수 있습니다.
- 네트워크 폴더와 네트워크 드라이브는 인덱싱하지 않습니다. UNC 경로를 즐겨찾기에 추가해 탐색할 수 있습니다.
- 접근 권한이 없는 폴더는 건너뜁니다. 관리자 인덱싱도 Windows 보호 폴더 전체의 접근을 보장하지 않습니다.
- 덮어쓰기는 병합 방식이며 교체 전 파일은 휴지통으로 보관합니다. 덮어쓴 작업의 실행 취소와 재실행 이후의 작업 기록 복원은 지원하지 않습니다.
- 베타의 업데이트 버튼은 GitHub 릴리스 페이지를 엽니다. 자동 다운로드·설치는 제공하지 않습니다.
- 설치 EXE는 코드 서명되지 않았으며 Windows에서 알 수 없는 게시자로 표시될 수 있습니다.

문제 제보는 [Issues](https://github.com/junhyeok928/QuadFinder/issues)에 재현 방법과 함께 남겨 주세요. 개인 파일이나 비밀번호가 포함되지 않도록 확인해 주세요.
