# QuadFinder v0.14.0-beta.5

검색 결과 추가 로딩과 전체 선택 범위를 개선하고, 파일 변경 감시와 작업 큐의 안정성을 보강했습니다.

## 변경 사항

- 검색 결과를 처음 1,000개 불러온 뒤 **다음 1,000개 불러오기**로 계속 확장할 수 있습니다. 불러온 결과는 새로고침 후에도 유지되며, 선택한 항목이 존재하면 선택도 유지됩니다.
- **Ctrl+A**로 숨김 설정을 반영한 폴더 전체를 선택합니다. 검색 화면에서는 불러온 결과 전체를 선택합니다.
- **Ctrl+Shift+A**로 현재 표시된 항목만 선택합니다. 접힌 그룹의 항목은 제외됩니다. 두 선택 명령을 우클릭 메뉴에서도 제공합니다.
- 파일 변경 감시 오류 시 1초부터 최대 60초 간격으로 자동 재연결합니다. 상태 표시줄과 인덱싱 진단에 재연결 상태를 표시하며, 검색 범위 감시가 복구되면 누락 가능성이 있는 하위 폴더 변경을 재점검합니다.
- 공개된 새 버전이 있으면 업데이트 버튼 오른쪽 위에 빨간 알림 점을 표시합니다. 실행 15초 후, 이후 6시간마다 확인하며 베타 버전은 새 베타와 정식 릴리스를 확인합니다. 버튼은 다운로드 페이지를 엽니다.
- 파일 작업 진행 중 완료 기록을 지운 뒤 새 작업을 추가하면 대기 상태에 남을 수 있던 문제를 수정했습니다.
- 실행에 사용하지 않는 설치 화면 이미지를 실행본에서 제외했습니다.

## 사용 안내

- 검색 정렬과 전체 선택은 **불러온 검색 결과**에 적용됩니다. 아직 불러오지 않은 결과는 선택되지 않습니다.
- 숨김 파일을 표시하지 않는 상태에서는 전체 선택에서도 숨김 파일이 제외됩니다.
- 베타 실행본은 업데이트를 자동으로 다운로드하거나 설치하지 않습니다.
- 변경 감지 자체를 지원하지 않는 볼륨은 수동 새로고침이 필요합니다.

## 검증

- 자동 테스트 83개 통과.
- 실제 Electron에서 2,105개 파일의 검색 결과 추가 로딩, 전체/표시 항목 선택, 숨김 파일·접힌 그룹 처리, 선택 및 새로고침 유지 확인.
- 기존 파일 작업·실행 취소·메뉴·배율·테마 통합 검사와 레이아웃 검사 통과.
- 실행본 소스·필수 리소스·언어 파일 패키지 검사 통과.
- 실제 USB 분리 및 절전 복귀 검사는 이번 검증 범위에 포함하지 않았습니다.

## 다운로드와 업데이트

| 파일 | 용도 |
| --- | --- |
| QuadFinder-Setup.exe | Windows 10/11 x64 설치 버전 |
| QuadFinder-0.14.0-beta.5-portable-x64.zip | 전체 압축을 풀고 QuadFinder.exe 실행 |
| SHA256SUMS.txt | 다운로드 파일의 SHA-256 검증값 |

기존 앱을 종료한 뒤 새 설치 파일을 실행하세요. 포터블 버전은 새 폴더에 전체 압축을 풀어 실행하세요. 두 버전 모두 `%APPDATA%\QuadFinder` 설정과 인덱스를 사용합니다. 설치 파일은 코드 서명되지 않았습니다.

## 로컬 실행본

`release/0.14.0-beta.5/QuadFinder-win32-x64/QuadFinder.exe`

기존 앱을 종료한 뒤 새 실행본을 여세요. 실행 폴더의 DLL과 리소스를 함께 유지해야 합니다. 설정과 인덱스는 `%APPDATA%\QuadFinder`를 사용합니다.
