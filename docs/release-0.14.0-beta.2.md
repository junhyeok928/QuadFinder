# QuadFinder v0.14.0-beta.2

## 수정 사항

- 삭제·실행 등 확인 버튼이 하나인 팝업에서 Enter를 누르면 확인 동작을 실행합니다.
- 취소 버튼으로 포커스를 옮긴 뒤 Enter를 누르면 취소하며, Esc로도 닫을 수 있습니다.
- 둘 다 유지·건너뛰기·덮어쓰기처럼 선택지가 여러 개인 팝업은 자동으로 덮어쓰지 않으며 포커스한 버튼을 실행합니다.

## 다운로드

| 파일 | 용도 |
| --- | --- |
| QuadFinder-Setup.exe | Windows 10/11 x64 설치 버전 |
| QuadFinder-0.14.0-beta.2-portable-x64.zip | 전체 압축을 풀고 QuadFinder.exe 실행 |

기존 설치 버전은 앱을 종료한 후 새 설치 파일을 실행하면 됩니다. 설정과 인덱스는 유지됩니다. 포터블 버전도 앱을 종료한 뒤 새 폴더에 압축을 풀어 실행하세요. 설정은 두 방식 모두 %APPDATA%\QuadFinder에 저장됩니다.

첫 인덱싱에는 시간이 걸릴 수 있으며 네트워크 폴더는 인덱싱에서 제외됩니다. 베타의 업데이트 버튼은 다운로드 페이지를 엽니다. 설치 파일은 코드 서명되지 않았습니다.
