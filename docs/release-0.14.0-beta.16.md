# QuadFinder v0.14.0-beta.16

검색 반응과 대용량 인덱싱의 처리 속도·안정성을 개선한 베타 버전입니다.

## 주요 변경

- 1~2글자 파일명 검색은 메모리의 이름 목록에서, 3글자 이상 검색은 전용 검색 색인에서 처리합니다.
- 결과 1,000개를 먼저 표시하고, 더 있는 경우 `1,001개 이상`으로 안내합니다. 다음 결과를 계속 불러올 수 있습니다.
- 입력 대기를 줄이고 한글 조합 중 중복 검색, 연속 검색의 깜빡임, 오래된 검색 응답을 개선했습니다.
- 검색 결과 표시 전에 모든 파일 속성을 다시 읽던 대기를 제거했습니다.
- 인덱싱 준비와 대용량 폴더 처리 중에도 검색·중단 요청을 처리하도록 작업을 나눴습니다.
- 파일별 중복 데이터베이스 조회를 줄이고 작은 저장 작업을 묶어 디스크 쓰기 부담을 줄였습니다.
- 폴더 삭제 시 하위 항목부터 정리해 중단 후 남은 항목을 다시 확인할 수 있도록 했습니다.
- 변경 감지용 파일 조회에서도 숨김·시스템·읽기 전용 속성을 유지합니다.
- 검색 오류가 발생하면 제한 시간까지 기다리지 않고 바로 알립니다.

## 다운로드

- `QuadFinder-Setup.exe`: 설치 또는 기존 설치본 업데이트
- `QuadFinder-0.14.0-beta.16-portable-x64.zip`: 압축 해제 후 실행
- `SHA256SUMS.txt`: 다운로드 파일의 SHA-256 확인값

기존 QuadFinder를 완전히 종료한 뒤 업데이트하거나 새 실행 파일을 사용하세요. 시작 시 파일명 목록을 메모리에 준비하므로 파일 수에 따라 준비 시간과 추가 메모리가 필요합니다. 기존 검색 설정과 색인을 재사용합니다.

검증: 전체 자동 테스트 109개 통과. 검색·추가 결과 로딩·색인 변경·취소·삭제·Windows 파일 속성 회귀 검사를 포함합니다.
