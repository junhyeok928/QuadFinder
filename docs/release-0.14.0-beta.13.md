# QuadFinder v0.14.0-beta.13

기본 우클릭 메뉴에 터미널 열기와 속성을 추가하고, 메뉴·검색·미리보기의 안정성과 대량 파일 처리 성능을 개선했습니다.

## 변경 사항

- 기본 우클릭 메뉴에서 현재 폴더 또는 선택한 폴더를 터미널로 열 수 있습니다. Windows Terminal이 없으면 Windows PowerShell을 사용합니다.
- 속성 메뉴의 이름과 배치를 정리하고, 속성 창이 메인 창 뒤로 밀리는 문제를 수정했습니다. 단일 파일·폴더 속성은 전체 클래식 메뉴를 구성하지 않고 직접 엽니다.
- 추가 옵션 표시로 연 클래식 메뉴의 포커스 전환, Esc 닫기 및 반복 열기 처리를 보완했습니다.
- 정렬 비교 설정을 재사용하고 그룹화 계산, 대량 선택 표시, 목록 셀의 중복 계산을 줄였습니다.
- 같은 썸네일의 진행 중 요청을 공유하고, 화면을 떠나거나 다시 그린 목록의 남은 썸네일 작업을 중단합니다.
- 빠른 선택 변경 시 마지막 항목만 미리보기를 요청하며, 이전 요청이 새 화면을 덮지 않도록 했습니다. 수정 시간이 같아도 파일 크기가 바뀌면 미리보기를 갱신합니다.
- 이전 검색의 오류가 새 폴더 화면에 반영되거나, 검색 결과를 여는 도중 탭을 바꾸면 다른 탭에 파일이 선택되는 문제를 수정했습니다.
- 관리자 인덱싱 요청에서 기존 작업 종료·재시작 대기와 PowerShell 실행을 제거했습니다. 현재 작업에서 Windows 승인을 직접 요청하며 취소하면 일반 권한으로 인덱싱을 재개합니다.

## 검증

- 전체 자동 테스트 98개 및 실제 Electron UI 회귀 검증을 통과했습니다.
- 파일명 20,000개 정렬 벤치마크에서 동일한 정렬 결과로 중앙값 약 983ms → 49ms를 기록했습니다. 정렬 처리만 측정한 로컬 결과이며 전체 앱 속도를 의미하지 않습니다.
- 관리자 승인 성공·취소 후 재개는 자동 테스트로 검증했습니다. 실제 UAC 팝업 표시 시간은 측정하지 않았으며 Windows 상태에 따라 달라집니다.

## 다운로드

| 파일 | 용도 |
| --- | --- |
| QuadFinder-Setup.exe | Windows 10/11 x64 설치 마법사 |
| QuadFinder-0.14.0-beta.13-portable-x64.zip | 전체 압축을 풀고 QuadFinder.exe 실행 |
| SHA256SUMS.txt | 다운로드 파일의 SHA-256 검증값 |

기존 앱을 종료한 뒤 설치하거나 포터블 파일을 새 폴더에 풀어 실행하세요. 설정과 인덱스는 `%APPDATA%\QuadFinder`에 저장됩니다. 설치 파일은 코드 서명되지 않았습니다.
