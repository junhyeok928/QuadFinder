# QuadFinder v0.14.0-beta.4

Windows 11 형식의 기본 우클릭 메뉴를 적용하고 메뉴 조작을 개선했습니다.

## 변경 사항

- 기본 우클릭 메뉴에 잘라내기·복사·붙여넣기·이름 바꾸기·공유·삭제 아이콘을 배치했습니다.
- 빈 공간의 보기·정렬·분류 옵션을 옆으로 펼치는 하위 메뉴로 제공합니다.
- 실제 파일 클립보드 상태에 따라 붙여넣기 버튼을 활성화합니다.
- Esc로 메뉴를 닫으면 파일 목록으로 포커스가 돌아갑니다.
- ‘더 많은 옵션 표시’, Shift+우클릭 또는 Shift+F10으로 Windows 클래식 시스템 메뉴를 엽니다. 설치된 압축 도구 등 셸 확장은 여기에서 사용할 수 있습니다.

기본 메뉴 화면은 앱에서 구현한 Windows 11 형식이며, 탐색기의 최신 메뉴 자체를 임베드하는 방식은 아닙니다.

## 다운로드와 업데이트

| 파일 | 용도 |
| --- | --- |
| QuadFinder-Setup.exe | Windows 10/11 x64 설치 버전 |
| QuadFinder-0.14.0-beta.4-portable-x64.zip | 전체 압축을 풀고 QuadFinder.exe 실행 |
| SHA256SUMS.txt | 다운로드 파일의 SHA-256 검증값 |

기존 앱을 종료한 뒤 새 설치 파일을 실행하세요. 설정과 인덱스는 유지됩니다. 포터블 버전은 새 폴더에 전체 압축을 풀어 실행하세요. 두 방식 모두 설정은 `%APPDATA%\QuadFinder`에 저장합니다.

첫 인덱싱에는 시간이 걸릴 수 있으며 모든 네트워크 폴더는 인덱싱에서 제외됩니다. 베타의 업데이트 버튼은 다운로드 페이지를 엽니다. 설치 파일은 코드 서명되지 않아 Windows SmartScreen 평판 경고가 나타날 수 있습니다.
