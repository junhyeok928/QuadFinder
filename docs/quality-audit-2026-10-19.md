# 추가 품질 점검 · 2026-10-19

최근 변경한 드래그·팝업·클립보드·작업 창을 중심으로 코드와 재현 시나리오를 점검했습니다.

## 확인하고 수정한 문제

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| 파일 복사 직후 경로 복사 시 마지막 내용이 덮일 수 있음 | 외부 셸 도우미의 파일 클립보드 쓰기와 Electron의 비동기 텍스트 쓰기가 서로 다른 순서로 완료 | 파일·텍스트 읽기/쓰기를 같은 큐로 직렬화하고 텍스트 쓰기 완료까지 대기 |
| 경로 복사 후 잘라내기 표시가 남음 | 파일 클립보드의 UI 상태를 초기화하지 않음 | 경로 텍스트로 교체한 뒤 파일 클립보드 상태와 잘라내기 표시 해제 |
| Enter를 길게 누르면 파일 열기 요청 반복 | 파일 목록 키 처리에서 반복 키 입력을 구분하지 않음 | 최초 입력만 처리하고 반복·한글 조합 중 입력은 무시 |

파일 정보 화면은 실제 렌더링으로 숫자 표시가 정상임을 확인했습니다. 변경하지 않았습니다.

## 검사 범위

- 파일 복사·이동·충돌·덮어쓰기·취소·휴지통·실행 취소
- 같은 폴더 드롭 무동작, 경로 별칭, 명시적인 같은 폴더 사본 만들기
- 클립보드 처리 순서와 한 번 클릭한 뒤 붙여넣기
- 팝업 9종의 Enter, 입력값 검증, Esc 취소
- Windows 시스템 메뉴와 다른 폴더의 복수 선택
- 외부 파일 드래그 IPC 및 경로 검증
- 작업 창 자동 닫기와 수동으로 연 내역 유지
- 휠 스크롤 애니메이션 제거, 배율·테마·분할 창·선택·뒤로 가기
- SQLite 인덱스 저장, 변경 반영, 접근 실패·시간 초과, 네트워크 인덱싱 제외

단위 테스트 72개 외에 실제 Electron 통합 검사와 디자인 검사를 사용합니다. 클립보드 순서·잘라내기 표시·Enter 반복 입력은 새 회귀 검사에 추가했습니다.

## 다음 개선 후보

1. **드라이브 재연결·절전 복귀 시 파일 감시 복구 강화** — 현재 감시 오류 처리와 재등록 흐름을 보완할 여지가 있습니다. 실제 USB 연결 해제·복귀 및 절전 시나리오로 검증하는 것이 다음 단계입니다.
2. **설정 백업·복원** — 즐겨찾기·레이아웃을 별도 보관하고 설정 파일 손상 시 복원하는 기능을 권장합니다.
3. **진단 로그 내보내기** — 인덱싱·파일 작업 실패를 재현 정보와 함께 내보내면 사용자 환경별 문제 확인에 도움이 됩니다. 파일 경로 등 개인정보 제외 옵션이 필요합니다.

이 후보들은 이번 수정에 포함하지 않았습니다. 실제 NAS 연결·USB 분리·절전 복귀 등 하드웨어와 외부 서비스에 의존하는 검사는 별도 시나리오로 남겨두었습니다.
