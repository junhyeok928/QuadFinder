# 버전 관리

- 첫 정식 릴리스: `1.0.0`.
- 버그 수정·성능 및 UI 개선: 패치 버전 증가 (`1.0.1`).
- 하위 호환성을 유지하는 기능 추가: 부 버전 증가 (`1.1.0`).
- 설정·데이터·외부 인터페이스 호환성이 깨지는 변경: 주 버전 증가 (`2.0.0`).
- 검증용 배포만 `-beta.N`을 사용하고 GitHub prerelease로 표시합니다. 정식 버전은 prerelease를 끄고 latest로 지정합니다.
- `package.json`을 버전 원본으로 사용하며 태그(`v<version>`), 릴리스 노트, 설치 프로그램 및 포터블 ZIP 버전을 일치시킵니다.
- 이미 공개한 버전의 태그나 파일을 바꾸지 않고 새 버전으로 배포합니다.
