# QuadFinder v0.14.0-beta.3

파일 드래그와 Windows 연동을 개선하고, 클립보드·팝업·스크롤 동작을 다듬었습니다.

## 변경 사항

- Windows 시스템 우클릭 메뉴를 연결하고 파일 작업과 실행 취소 흐름을 개선했습니다.
- 메일·브라우저 등 외부 프로그램에 파일을 드래그하여 전달할 수 있습니다.
- 같은 폴더에 파일을 다시 드롭하면 복사·이동하지 않습니다. 명시적인 복사·붙여넣기로 사본을 만드는 동작은 유지합니다.
- 모든 앱 팝업에서 Enter는 확인·삭제·변경 등 긍정 버튼을 실행합니다. 취소 버튼에 포커스가 있어도 동일하며, 취소는 클릭 또는 Esc로 할 수 있습니다. 충돌 팝업의 기본 선택은 ‘둘 다 유지’입니다.
- 복사 직후 붙여넣기와 파일 목록 포커스 처리를 개선했습니다.
- 파일 복사 직후 ‘경로 복사’ 시 클립보드가 뒤늦게 덮이는 문제와 잘라내기 표시가 남는 문제를 수정했습니다.
- Enter를 길게 눌렀을 때 파일 열기가 반복되는 문제를 수정했습니다.
- 자동으로 열린 파일 작업 창은 작업 완료 후 닫힙니다. 직접 연 작업 내역은 유지됩니다.
- 휠 스크롤의 긴 애니메이션을 제거해 파일 목록이 즉시 반응하도록 했습니다.

## 다운로드와 업데이트

| 파일 | 용도 |
| --- | --- |
| QuadFinder-Setup.exe | Windows 10/11 x64 설치 버전 |
| QuadFinder-0.14.0-beta.3-portable-x64.zip | 전체 압축을 풀고 QuadFinder.exe 실행 |
| SHA256SUMS.txt | 다운로드 파일의 SHA-256 검증값 |

기존 앱을 종료한 뒤 새 설치 파일을 실행하세요. 설정과 인덱스는 유지됩니다. 포터블 버전은 새 폴더에 전체 압축을 풀어 실행하세요. 두 방식 모두 설정은 `%APPDATA%\QuadFinder`에 저장합니다.

첫 인덱싱에는 시간이 걸릴 수 있으며 모든 네트워크 폴더는 인덱싱에서 제외됩니다. 베타의 업데이트 버튼은 다운로드 페이지를 엽니다. 설치 파일은 코드 서명되지 않았습니다.

단위 테스트 72개와 실제 Electron 통합·디자인·패키지 검사를 통과했습니다. USB 분리·재연결과 절전 복귀는 이번 점검에서 직접 시험하지 않았습니다.
