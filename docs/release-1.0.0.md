# QuadFinder v1.0.0

첫 정식 버전입니다. 기존 베타의 설정과 색인을 유지합니다.

## 변경 사항

- 선택된 드라이브에서도 사용량과 남은 용량 영역을 구분할 수 있도록 막대 색상과 테두리를 개선했습니다. 어두운 테마와 밝은 테마 모두 적용됩니다.
- Windows 기본 연결 프로그램 아이콘, 드래그 이동 및 Ctrl 복사, 검색·인덱싱 개선을 포함합니다.
- 버전을 1.0.0으로 전환했습니다. 앞으로 버그 수정은 1.0.x, 기능 추가는 1.x.0, 호환성 변경은 다음 주 버전으로 관리합니다.

## 다운로드

- `QuadFinder-Setup.exe`: 설치 및 업데이트
- `QuadFinder-1.0.0-portable-x64.zip`: 압축 해제 후 실행
- `SHA256SUMS.txt`: 파일 검증값

기존 앱을 완전히 종료한 뒤 업데이트하세요.
