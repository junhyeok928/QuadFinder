# QuadFinder v0.14.0-beta.6

클래식 우클릭 메뉴에서 ‘여기에 PowerShell 창 열기’ 등 폴더 명령을 실행하면 ‘연결된 응용 프로그램이 없습니다’ 오류가 발생하던 문제를 수정했습니다.

## 수정 사항

- 폴더 빈 공간의 클래식 메뉴에 등록된 실행 명령에 현재 폴더 경로와 작업 폴더를 전달합니다. 선택 항목이 없는 배경 메뉴를 통해 실행할 때 발생하던 연결 프로그램 오류를 해결했습니다.
- 등록 명령의 환경 변수와 폴더 경로 인수(`%V`, `%1`, `%L`, `%W`)를 처리합니다. 한글·공백·특수문자가 포함된 경로와 드라이브 루트 경로를 지원합니다.
- 일반 파일 메뉴와 COM 셸 확장 명령은 Windows의 기존 메뉴 처리기를 사용합니다.
- 클래식 메뉴를 열 때 도우미와 셸 확장을 매번 새로 시작하던 비용을 줄였습니다. 앱 시작 후 백그라운드에서 준비하고, 폴더 배경 메뉴의 클립보드 확인도 같은 도우미에서 처리합니다.
- 셸 도우미가 비정상 종료되면 현재 요청에 오류를 알리고 다음 메뉴 요청에서 복구합니다. 실행 명령을 자동으로 재시도하지 않아 중복 실행을 방지합니다.

## 검증

- 자동 테스트 86개와 실제 Electron 통합·레이아웃 검사를 통과했습니다.
- 실제 Windows 배경 메뉴에 임시 테스트 명령을 등록해 오류를 재현하고 수정 후 실행을 확인했습니다.
- 실제 PowerShell 실행, Unicode·공백·특수문자·환경 변수·드라이브 루트 경로 전달을 자동 검사했습니다.
- 도우미 재사용·순차 요청·비정상 종료 후 복구를 검사했습니다. 메뉴 준비 시간은 설치된 셸 확장과 저장 장치 상태에 따라 달라질 수 있습니다.
- 테스트 등록은 검사 후 제거하며 사용자 PowerShell 설정과 기본 연결 프로그램을 변경하지 않습니다.

기존 앱을 종료한 뒤 새 설치 파일을 실행하세요. 포터블 버전은 새 폴더에 전체 압축을 풀어 실행하세요. 두 버전 모두 `%APPDATA%\QuadFinder`의 설정과 인덱스를 사용합니다. 설치 파일은 코드 서명되지 않았습니다.
