# 인덱싱 점검 — 0.5.1

## 수정 사항

- UNC 공유와 Windows 네트워크 드라이브를 검색 대상·감시·캐시 복원에서 제외합니다. 기존 검색 대상의 네트워크 경로는 즐겨찾기로 전환합니다. 폴더 탐색과 파일 작업은 유지합니다.
- 폴더 읽기에 15초 제한을 두고, 검색 대상 변경 시 대기를 취소합니다. 응답하지 않는 OS 호출이 뒤늦게 끝나도 취소된 결과를 반영하지 않습니다.
- 변경 알림에서는 파일 메타데이터 또는 폴더의 직계 목록을 갱신하고 새 하위 폴더만 재귀 수집합니다. 부모 알림과 함께 온 명시적 하위 파일 알림도 처리합니다.
- 대소문자만 다른 알림이 서로를 제거하던 문제를 수정했습니다. 대량 알림의 전체 수집 대상 병합은 정렬로 처리합니다.
- 접근 실패 시 기존 항목을 보존하고 경고합니다. 삭제는 부모 목록 확인 후 반영합니다.
- 수집 중에도 확인한 항목을 검색할 수 있고, 폴더 수와 현재 경로를 상태 표시줄에 표시합니다.
- 변경 없는 전체 수집에서는 캐시를 다시 쓰지 않습니다. 캐시는 허용된 경로와 정상 레코드만 복원합니다.
- 25만 항목에 도달해도 기존 항목 갱신과 삭제는 계속 처리합니다. 링크 경유 증분 갱신도 차단합니다.
- 인덱스 작업 종료 시 검색 재시도로 복구하며, Windows 속성 조회 실패 시 기본 검색 결과를 반환합니다.

## 확인

- 실제 로컬 검색 대상 5곳: 49,488개 파일·폴더, 7,969개 폴더, 약 7.1초, 접근 실패 0곳. 사용자 캐시를 쓰지 않는 별도 작업으로 측정했습니다. 환경과 파일 변경에 따라 시간은 달라집니다.
- 자동 테스트에서 지연·취소·접근 실패·삭제·중복 알림·캐시 보존·용량 제한·링크 경유를 검증했습니다.
- 실제 공유 폴더는 읽기만 수행했습니다. 폴더 추가, 탐색, 하위 트리, 저장·복원은 통과하고 검색 대상 추가는 거절되는 것을 확인했습니다.
- Electron 화면 검증에서 일반·최소 창 크기와 사이드바 크기 변경에 넘침이 없습니다.

자체 파일 순회 방식입니다. 로컬 파일 변경이 계속 발생하면 증분 갱신이 이어질 수 있으며, Everything의 NTFS MFT/USN 방식은 아직 구현하지 않았습니다.
