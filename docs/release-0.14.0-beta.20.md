# QuadFinder v0.14.0-beta.20

파일 드래그의 기본 동작을 **이동**으로 바꾸고, 대상 폴더와 실행할 작업을 더 명확하게 표시했습니다. **Ctrl을 누른 채 드래그하면 복사**합니다.

## 개선 사항

- Windows 기본 연결 프로그램 아이콘을 표시합니다. ZIP은 반디집, HWP는 한글 등 각 PC의 연결 설정을 따릅니다.
- 화면에 보이는 파일부터 아이콘을 읽고 확장자별 캐시를 사용합니다. 사진 미리보기와 실행 파일·바로가기 고유 아이콘은 유지합니다.

- 폴더 행·아이콘 위로 드래그하면 굵은 테두리와 배경색으로 대상 폴더를 강조합니다.
- 커서 옆에 대상 폴더와 이동/복사 안내가 표시되며 Ctrl 키에 따라 안내가 바뀝니다. 사이드바 폴더에도 적용됩니다.
- 드롭 완료, 드래그 취소, Esc, 대상 영역 벗어남 시 강조와 안내를 해제합니다.
- 외부 파일 정보를 가져오는 동안 화면이 바뀌어도 처음 놓았던 대상 폴더와 이동/복사 선택을 유지합니다.
- 파일 작업이 실패하거나 일부 실패한 경우 작업 창을 자동으로 숨기지 않아 오류 내용을 확인할 수 있습니다.
- 사용 안내에 기본 드래그 이동과 Ctrl 복사 방법을 추가했습니다.
- 기존 검색 및 인덱싱 성능·안정성 개선을 포함합니다.

## 다운로드

- `QuadFinder-Setup.exe`: 설치 및 업데이트
- `QuadFinder-0.14.0-beta.20-portable-x64.zip`: 압축 해제 후 실행
- `SHA256SUMS.txt`: 다운로드 파일의 SHA-256 확인값
