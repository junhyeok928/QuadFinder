인덱싱 상태

관리자 권한을 허용하면 읽기 전용 인덱싱 도우미로 보호 폴더를 다시 확인합니다. 파일의 권한이나 소유자는 변경하지 않습니다. 일부 Windows 보호 폴더는 계속 제한될 수 있습니다.

이름 변경

검색 범위

PC의 로컬 드라이브를 자동으로 검색합니다. 폴더를 따로 추가할 필요가 없습니다. 네트워크 폴더는 제외하며, 접근 권한이 없는 폴더는 건너뜁니다.

폴더 추가

로컬 폴더 또는 네트워크 공유 경로를 입력하세요. 네트워크 폴더는 탐색만 가능하며 검색 인덱싱에서 제외됩니다.

바로가기 표시 이름

실제 폴더 이름은 변경하지 않습니다. 비우면 원래 이름을 사용합니다.

자세히 보기 열

표시할 열을 선택하고 순서를 조절하세요. 열 제목도 드래그하여 옮길 수 있습니다.
